# История буфера обмена

Super+V открывает историю ClipHist в Fuzzel: поиск, Enter копирует выбранную
запись, Shift+Delete удаляет её, Esc закрывает меню. Для вставки в приложение
используй Ctrl+V. Super+Shift+V открывает настройки записи и очистку.

Установщик добавляет файлы и пакет `cliphist`. После установки включи запись
внутри сессии Hyprland:

```sh
systemctl --user daemon-reload
desktop-clipboard resume
```

Запись не включается установщиком автоматически. Службы
`desktop-clipboard@text.service` и `desktop-clipboard@image.service` привязаны к
`graphical-session.target`; после включения они также запускаются в других
графических сессиях этого пользователя, если там доступен Wayland.
`desktop-clipboard pause` останавливает обе службы и отключает их автозапуск.
`desktop-clipboard status` показывает `recording`, `paused` или `degraded`.
При неполном состоянии выбери Resume / repair recording в настройках.

История хранит 200 записей текста и изображений в `~/.cache/cliphist/db`.
Лимит одной записи — 5 МБ, время чтения — 5 секунд. Пустой ввод, TIFF/BigTIFF
и данные с меткой чувствительного содержимого пропускаются. Обычный текст без
этой метки сохраняется, включая пароли; для исключения используй паузу.
Очистка через меню удаляет историю и текущий буфер после подтверждения.

Оформление задаёт `~/.config/desktop-clipboard/fuzzel.ini`, лимиты истории —
`~/.config/cliphist/config`. Наблюдатели имеют ограничения памяти, CPU и числа
процессов. По умолчанию установлен Python-фильтр; совместимый Rust-вариант
и инструкции сборки находятся в `optional/rust/desktop-clipboard-store/`.
