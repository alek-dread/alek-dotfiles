# Интерактивная установка: статическая проверка 28 октября 2026

Добавлены три вопроса: использовать Terra (по умолчанию да), установить
гритер Arthur из исходного ПК (по умолчанию нет), выбрать Iosevka или
JetBrains Mono. Все ответы можно передать параметрами командной строки.
Без Terra предлагается JetBrains Mono; Iosevka доступна без Terra только
при уже установленных пакетах. Закрытый ввод не считается согласием.

Отказ от Terra исключает её из всех DNF-команд этого установщика и не меняет
системную конфигурацию уже подключённой Terra. Базовый список пакетов больше
не содержит terra-release и обязательных пакетов Iosevka. Выбор шрифта
рендерится при проверке и установке одинаково; исходные файлы не изменяются.
Конфликты существующих домашних файлов по-прежнему останавливают установку.

Гритер собирается обычным пользователем из включённого в репозиторий архива.
До изменения конфигурации создаётся резервная копия; при ошибке настройки
восстанавливаются файлы и прежняя ссылка display-manager.service. Используется
пакетный пользователь greetd, применяются SELinux-контексты. Включение службы
отложено до следующей загрузки; текущая сессия не останавливается.

Проверка выполнена только статически:

- `sh -n install.sh` и разбор изменённых Python-файлов через `ast.parse`.
- `git diff --check` и ручной просмотр веток выбора, формирования пакетов,
  предварительной проверки, резервного копирования и отката гритера.
- Локальный кэш DNF подтверждает пакеты Iosevka в Terra и JetBrains Mono
  в Fedora; справка DNF5 подтверждает `--disable-repo` с шаблонами.
- RPM spec разобран через `rpmspec -q --buildrequires`, без сборки.
- Добавлены регрессионные тесты отказа от Terra, выбора шрифта, закрытого
  ввода, конфликтов и восстановления гритера. Тесты не запускались.

Установщик, сборка, виртуальные машины и изменение действующей системы
не запускались. Поведение установки и входа в систему этим просмотром
не подтверждено. Исходная PAM-конфигурация берётся из пакета greetd.
