# Arthur

Текущая тема рабочего стола, синхронизирована 23 октября 2026.
Основа палитры: Arthur из iTerm2-Color-Schemes.

| Назначение | Цвет |
| --- | --- |
| Фон | `#1c1c1c` |
| Текст | `#ddeedd` |
| Акцент и вторичный текст | `#bbaa99` |
| Вторичная поверхность | `#3d352a` |
| Неактивная рамка / наведение занятого стола | `#4d4d4d` |
| Кремовый текст Zathura | `#ddccbb` |
| Критические уведомления | `#cd5c5c` |

Hyprland: нулевые зазоры и скругления, непрозрачные окна, без теней, blur
и анимаций. Активная рамка — 2 px, градиент `#bbaa99` → `#ddccbb`, 45°.
Просмотр медиа Telegram открывается плавающим окном.

Waybar: высота 26 px, девять столов с шириной кнопки 26 px, текстовые
индикаторы EN/RU, VOL/MUTE, NET/WLAN. Справа полужирный шрифт.
Активный стол бежевый, занятый — тёмно-коричневый, пустой — без заливки.
Состояния столов получает общий наблюдатель IPC для Lua API Hyprland.

Шрифты: Iosevka Aile 14 px в панели и 11 pt в меню/уведомлениях;
IosevkaTerm Nerd Font Mono 13 pt в терминале, Adwaita Mono 11 pt в Zathura.
Fuzzel: восемь строк, шаг 28 px, подсказка Run. Mako: ширина 360 px.
Hyprlock: поле 320×48 px, часы 40 pt. Выбор области снимка/записи —
бежевый контур на полупрозрачном тёмном фоне.

Alacritty сохраняет оригинальные ANSI-цвета Arthur. Zathura использует
кремовый текст и тёмный фон; recolor-keephue отключён.
Оба приложения получают отдельные конфиги из `~/.config/alek-hyprland/`.
Waybar и Fuzzel запускают терминал через `desktop-terminal`.

GTK/Qt сохраняют нативные виджеты. Дополнительные настройки GTK, Firefox,
Neovim, greeter и исходного ПК лежат в `optional/` и не устанавливаются
автоматически. По умолчанию фон однотонный; изображение выбирается через
`desktop-wallpaper /path/to/image.jpg`.
