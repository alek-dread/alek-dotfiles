# Rust-помощники

Исходники нативных помощников действующего рабочего стола на 28 октября 2026:

- `waybar-workspace/`: IPC Hyprland, состояния девяти рабочих столов, сигналы Waybar.
- `desktop-clipboard-store/`: ограничение ввода `wl-paste` перед передачей ClipHist.

Здесь сохранены Cargo.toml, Cargo.lock, исходники, существующие тесты и скрипты
измерений. Бинарники и `target/` не публикуются. Требуется Rust 1.85 или новее;
инструкции находятся в README каждого каталога. Для Waybar первая сборка требует
загрузки зафиксированных зависимостей. Фильтр буфера сторонних crates не использует.

Общий установщик сохраняет Python-реализации и не требует Rust. Сборка и замена
помощников выполняются вручную. Текущая проверка репозитория описана в
`docs/review-2026-10-28.md`.
