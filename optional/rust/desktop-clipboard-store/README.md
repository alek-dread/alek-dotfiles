# desktop-clipboard-store

Нативный обработчик `wl-paste --watch` на Rust. Собирается без сторонних
Rust-зависимостей и без сети. Для запуска нужны Linux >= 5.3, glibc >= 2.36,
системные libc/libgcc_s и `/usr/bin/cliphist`.

Сохраняет данные только при `CLIPBOARD_STATE=data`. Пропускает пустой ввод,
данные больше 5 000 000 байт и четыре сигнатуры TIFF/BigTIFF. TIFF и превышение
лимита обнаруживаются сразу, не дожидаясь EOF. Остальные байты передаются
неизменными в `/usr/bin/cliphist store`. Права создаваемых файлов ограничивает
`umask 077`; stdout/stderr заглушены. Путь ClipHist фиксирован, PATH не используется.

На получение ввода отведено 5 секунд; на запуск, запись в ClipHist и ожидание его
завершения — ещё 8 секунд. Ожидание использует `poll` и дескриптор процесса
`pidfd`, без рабочих потоков и опроса по таймеру. Запись в дочерний процесс
неблокирующая. При ошибке или тайм-ауте дочерний процесс завершается и собирается.
Код возврата ClipHist передаётся вызывающему процессу; собственные ошибки дают 1,
пропущенные записи — 0. Фоновый демон не добавляется.

Буфер начинается с 8 КиБ и растёт до 5 000 001 байта. Release-сборка использует
оптимизацию скорости, LTO и удаление отладочных символов.

## Сборка и проверки

```sh
cd optional/rust/desktop-clipboard-store
cargo build --offline --release
cargo test --offline --release
cargo clippy --offline --all-targets -- -D warnings
cargo fmt --check
DESKTOP_CLIPBOARD_STORE_TEST_BIN="$PWD/target/release/desktop-clipboard-store" \
  python3 -B test_clipboard.py
```

Rust-тесты проверяют границы размера, частичный ввод/вывод, точные байты,
тайм-ауты, ранний выход ClipHist, сигналы и сбор дочернего процесса. Python-тесты
проверяют интерфейс меню и настоящий бинарник с ClipHist на временной базе.
Рабочая история и текущий буфер в этих тестах не изменяются.

## Установка

Из этого каталога после сборки:

```sh
install -m 755 target/release/desktop-clipboard-store ~/.local/libexec/desktop-clipboard-store
```

`install.sh` устанавливает Python-версию с теми же ограничениями размера,
форматов и времени. Rust-обработчик используется наблюдателями при следующем
копировании; перезапуск служб не требуется. Для возврата к Python скопируй
`home/.local/libexec/desktop-clipboard-store` из репозитория на то же место.

`benchmark.py` принимает пути к Python-обработчику и собранному бинарнику;
использует временные базы ClipHist. Измерения и тесты не запускаются установщиком.
